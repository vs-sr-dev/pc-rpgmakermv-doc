## Rules this repository was written under

* **nothing was executed, installed or emulated.** The object is an editor,
  three players, a JavaScript runtime and 2.9 GB of assets, and the temptation
  here was a different one: **the engine is source, and source is read, not
  run.**
* **every figure names its denominator.** There are nine and the second is that
  the shop believes the tree weighs 2,925,487,466 bytes and it weighs
  2,925,489,709.
* **every file-selecting tool selects by magic**, including one inherited tool
  repaired here to obey it.
* **no absolute path of this machine appears anywhere** — checked over 667
  tracked files with a positive control that fires, after that check found two
  real violations inside this repository's own captured output.
* **what the owner of the copy made is not the object.** The rule's first
  re-application returns the empty set: `projects\` holds one 51-byte file and
  Steam wrote it.
* **the documents are in English and the conversation was not.**

`docs/` is the argument, `notes/` is the evidence as the commands produced it,
and `tools/` is the box — 568 Python files, of which six were written here and
four repaired.
